# Naskah yang dipulihkan dari percakapan

`week-2026-11-11-narration.json` berisi teks yang sebelumnya dikirim sebagai input TTS untuk sembilan topik 11–13 November 2026, target editorial WIB, sumber, dan batas fakta. Teks dipulihkan dari catatan percakapan, bukan dari arsip sumber asli.

**Tidak dipulihkan:** sembilan MP4, thumbnail, audio voice-05, gambar, timeline, subtitle, renderer, storyboard, dan hasil QA sebelumnya. Bila ZIP lama ditemukan dan diunggah kembali, verifikasi checksum dan utamakan file asli. Berkas ini tidak membuat atau mengubah jadwal publikasi.

Teks CTA menggunakan `ikuti knot theory`. Setelah suara dibuat atau dipulihkan, pelafalan serta sinkronisasi subtitle tetap harus ditinjau dengan mendengarkan.
