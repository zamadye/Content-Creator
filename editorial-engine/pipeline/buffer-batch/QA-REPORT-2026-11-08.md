## Batas operasional

- Tidak ada PR atau cron. Satu run memproses satu batch, tetapi perlu satu panggilan create per post/kanal dan pembacaan kembali. Hasil parsial atau tidak pasti wajib direkonsiliasi sebelum mengirim ulang.
- Minimal dua jam antarposting yang diperiksa runner. Hindari perubahan antrean langsung di Buffer selama batch berjalan; pemeriksaan ulang mengurangi, tetapi tidak menghilangkan, kemungkinan race.
- Salinan yang dapat diakses publik membutuhkan persetujuan terpisah. Master/backup tetap privat. QA fakta, hak, teknis, peninjauan manusia dan peninjauan kewajiban label AI tidak boleh dipalsukan.
- Kode membatasi sampai 100 post per batch; kapasitas akun dan rate limit Buffer mungkin lebih rendah. TikTok/Instagram, pengecualian jarak waktu dan host di luar allowlist memerlukan pengembangan dan pengujian tersendiri.
