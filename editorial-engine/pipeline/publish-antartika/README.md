# Antartika: penerbitan aman satu kali (7 Nov 2026)

Pengguna menyetujui publikasi segera pilot Antartika di YouTube Shorts dan Facebook Reels serta pengecualian khusus dari jeda dua jam terhadap posting Titik Buta FB pukul 15.00 WIB dan antara dua platform untuk pilot ini. Pengecualian untuk konten malam tidak diterapkan dalam skrip ini. Tidak mengubah Danau/Titik Buta. Asli tetap privat. User juga mengizinkan salinan Antartika sementara `anyone with link`; cabut hanya setelah kedua publikasi benar-benar terverifikasi.

Push ke request khusus memicu GitHub Actions dengan marker `[approved-antartika-run]`; action hanya `preflight` (read-only), `publish` (dua `shareNow`), atau `inspect` (read-only). GitHub runner membuat kunci RSA sementara dan memublikasikan public key/nonce pada check-run; operator menyegel ID salinan dan caption ke public key itu lalu mendorong ciphertext ke envelope terpisah. URL salinan tidak ada di source, request atau log. Report lengkap dikompresi/dienkripsi ke public key operator dan dikembalikan sebagai anotasi; kunci privat tetap lokal di luar repo. Tidak ada media atau kredensial dalam Git.

Preflight memeriksa SHA-256/ukuran salinan publik secara anonim, organisasi, kanal, seluruh antrean, serta dry-run payload. Dua-jam terhadap post lain tetap berlaku selain ID Titik Buta FB yang telah disetujui dan pasangan Antartika sendiri. Waktu post yang tak dapat diketahui memblokir pengiriman. `publish` mengulang pemeriksaan, memeriksa duplikat dan mengirim setiap platform **maksimal sekali**. Status `CREATE_UNCERTAIN` atau kehilangan report setelah mulai create: jangan retry, jalankan `inspect`/cek Buffer secara terpisah. `sent` dan tautan platform baru boleh disebut benar-benar terbit jika dibaca kembali; status `scheduled`/`sending` bukan bukti publikasi. Dry-run hanyalah pemeriksaan schema. Original voice pronunciation, subtitle synchronization and phone playback still require human review.

Kunci privat sementara bukan token Buffer dan tidak pernah dikirim ke Actions atau Git. Jangan menambahkan link media ke source publik. Bila private key lokal hilang setelah reset, laporan terenkripsi lama tidak dapat dibaca; cek Buffer lagi secara read-only, jangan membuat ulang post secara buta.
