# Skin textures

`skin_young_asian_male.jpg` and `skin_old_asian_female.jpg` are MakeHuman skin textures distributed by [vrm-avatar-maker](https://github.com/ffunch/vrm-avatar-maker/tree/46c185c8e94e01efb013e56cc9480ba7e9208e0d). Its ASSETS.md identifies these MakeHuman textures as CC0. The male texture is used on Dimas in the ride scene; the female texture is retained for future integration and is not currently applied. Eyeballs are procedural meshes.
