# QUALITY CONTROL CHECKLIST — ALL STAGES

**Episode ID:** EP-__  
**Review date:** YYYY-MM-DD · **Reviewer:**  

A stage is not approved while any critical check fails. Do not silently skip approval gates.

---

## Research

- [ ] Important claims supported by ledger IDs
- [ ] Primary sources available for core claims
- [ ] Dates and figures correct against sources
- [ ] Financial figures include currency, period, units, context, source
- [ ] Allegations labeled — never presented as proven facts
- [ ] Hypotheticals labeled as illustrative
- [ ] No invented figures / quotes / dates / legal outcomes

## Script

- [ ] Hook compelling; no forbidden openers
- [ ] Every scene advances the narrative; no dead repetition
- [ ] Language natural Indonesian; jargon explained on first use
- [ ] Claims map to ledger IDs
- [ ] Word count 1,100–1,500 (adjusted to pace)
- [ ] No exaggerated claims; no investment recommendations

## Storyboard

- [ ] Every scene has a visual purpose
- [ ] Character continuity vs. reference sheets
- [ ] Mechanisms understandable on screen
- [ ] Palette and style compliant with BRAND-CONFIG
- [ ] Text overlays planned for editing stage
- [ ] Evidence IDs / hypothetical labels present

## Animation

- [ ] Movement purposeful (discovery/explanation/conflict/reveal rules)
- [ ] Visual style consistent across scenes
- [ ] Graphics readable; no motion harms information
- [ ] No continuous shake, excessive zoom, unmotivated particles, random transitions

## Audio

- [ ] Narration clear: native Indonesian, natural pauses, investigative tone
- [ ] Music balanced — never competes with voice
- [ ] Sound effects support visual events; no excessive loudness changes

## Final Video

- [ ] Delivers the promise of the title
- [ ] Pacing appropriate for 8–12 min target
- [ ] All claims and visuals accurate to evidence
- [ ] Correct scene order; narration synchronized
- [ ] Clean transitions, readable typography, consistent palette
- [ ] No unsupported visual claims; hypotheticals labeled on screen
- [ ] Export: MP4 · H.264 · 1920×1080 · 16:9 · 24 FPS · AAC · YouTube-ready
- [ ] If rendering unavailable: remaining manual steps explicitly listed — never claim a video was produced

## Publishing Package

- [ ] 3 title variations (no clickbait/misleading)
- [ ] 3 thumbnail concepts (1280×720, one dominant subject, one conflict, 2–5 words, navy+amber, mobile-readable)
- [ ] Indonesian YouTube description + keywords + chapters/timestamps
- [ ] Source references listed
- [ ] Pinned comment · 2 Shorts concepts + scripts · 1 community post idea
- [ ] Shorts self-contained (9:16, 30–60 s)

## Editorial Integrity (any stage)

- [ ] No copied competitor scripts/sequences
- [ ] No impersonation of real people; no fabricated documentary footage
- [ ] FACT / INTERPRETATION / OPINION / HYPOTHESIS distinguished
- [ ] Corrections process in place if evidence changes
- [ ] Defamation risk reviewed
