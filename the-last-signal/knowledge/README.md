# Knowledge — THE LAST SIGNAL

Lima berkas, lima fungsi. Tidak ada dokumen lain: aturan tinggal di satu tempat,
sisanya bukti dan mekanisme.

| Berkas | Isi |
| --- | --- |
| **`ATURAN.md`** | **Satu-satunya dokumen aturan.** Naskah, visual, suara, subtitle, copywriting, distribusi, QC, daftar hitam, status implementasi. Kalau ada yang bertentangan dengan halaman ini, halaman ini menang. |
| `audio.md` | Pustaka aset audio: 30+ berkas, panjang, level, tag, dan cara memakainya. |
| `distribution.md` | Mekanisme unggah: dua platform, antrean, QC di runner, label AI, kegagalan yang sudah dibayar. |
| `drive.md` | Struktur arsip Google Drive dan batas apa yang boleh tinggal di repo. |
| `reference-design.md` | Bukti angka: bedah video pembanding (kamera 0,000 px/frame, 25 cut/25 s, caption 6 % tinggi layar, 0 celah sunyi). |

Berkas data (ditulis mesin, bukan dibaca sebagai aturan):
`episodes.jsonl` (catatan unggahan terakhir, dipakai gerbang jeda 55 menit) dan
`fb-reels-state.json` (status Reels).

## Cara memakai

1. Sebelum menulis naskah: baca `ATURAN.md` bagian II.
2. Sebelum membuat gambar: baca bagian III + `assets/characters/characters.json`.
3. Sebelum merender: baca bagian VIII (gerbang QC).
4. Sebelum mengunggah: baca bagian VI + VII.

## Yang sengaja tidak ada di sini

Tidak ada arsip episode, tidak ada analitik episode lama, tidak ada dokumen
"landasan" terpisah. Semuanya sudah diringkas ke `ATURAN.md` atau dihapus —
kalau sebuah aturan tidak muat di satu halaman, ia belum jadi aturan.
