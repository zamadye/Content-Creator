# releases/

Folder ini **kosong** hampir sepanjang waktu.

Isinya hanya media yang sedang menunggu diunggah: `publish-queue/*.json` menunjuk
ke berkas di sini, workflow mengangkutnya dari repo ke storage Zernio, lalu —
setelah unggahan sukses — berkasnya dihapus lagi dari repo dan diarsipkan di
Google Drive (`knowledge/drive.md`).

Kalau folder ini berisi lebih dari satu berkas, berarti ada unggahan yang
tertinggal: periksa `knowledge/fb-reels-state.json` sebelum menambah antrean baru.
